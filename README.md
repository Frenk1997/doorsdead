# Doors Death Macro

Макрос для фарма смертей в Roblox **DOORS** (Windows). Он сам нажимает клавиши и кнопки на экране:

1. выходит из лифта, берёт ключ и открывает дверь (по маршруту, который ты один раз записал);
2. ждёт смерти от Eyes (модификатор на глаза);
3. нажимает **«Возродиться»**;
4. снова быстро умирает;
5. нажимает **«Играть снова»** и повторяет всё по кругу, считая смерти.

> ⚠️ Автоматизация ввода может нарушать правила Roblox. Используешь на свой риск.

## Установка

1. Поставь [Python 3.10+](https://www.python.org/downloads/) (галочка **Add Python to PATH**).
2. Скачай репозиторий и запусти `start.bat` — он поставит `pynput` и откроет окно макроса.

Если Roblox запущен от администратора, запускай и макрос от администратора, иначе нажатия не дойдут.

## Настройка (один раз)

1. **Запомни кнопки.** Умри в игре, чтобы появился экран смерти. В окне макроса выбери имя `revive`,
   нажми «Захватить через 3 с» и наведи курсор на кнопку «Возродиться» (или наведи и нажми **F8**).
   То же самое для `play_again` — кнопка «Играть снова». Макрос запоминает координаты и цвет пикселя,
   по ним он понимает, что ты умер.
2. **Запиши маршрут.** Начни забег, стоя в лифте нажми **F7**, пройди путь: выход из лифта → ключ → дверь,
   снова **F7**. Маршрут сохранится в `route.txt` (клавиши, повороты камеры и задержки).
3. При необходимости поправь `cycle.txt` (кнопка «Открыть»): время ожидания лифта, загрузки и т.д.

## Запуск

- **F6** — старт/стоп цикла
- **F7** — запись маршрута
- **F8** — запомнить точку под курсором
- **F9** — аварийная остановка (отпускает все зажатые клавиши)

Если камера при повторе поворачивается не так, как при записи, поменяй «Множитель поворота».
Если макрос не замечает кнопку — увеличь «Допуск цвета» или захвати точку на более однотонной части кнопки.

## Команды сценариев

| Команда | Что делает |
|---|---|
| `wait 1.5` / `wait 1 2` | пауза (во втором случае — случайная от 1 до 2 с) |
| `press e 0.6` | нажать клавишу и держать 0.6 с |
| `down w` / `up w` | зажать / отпустить клавишу |
| `turn 300 0 0.3` | повернуть камеру (мышь на dx, dy) за 0.3 с |
| `click @revive` / `click 960 540` / `click` | клик по точке, координатам или на месте |
| `rclick`, `mdown left`, `mup left` | правый клик, зажать/отпустить кнопку мыши |
| `move @point` | переместить курсор |
| `wait_pixel @revive 90 метка` | ждать появления точки до 90 с, иначе перейти к метке |
| `wait_no_pixel @p 10 метка` | ждать, пока точка пропадёт |
| `if_pixel @p метка` / `if_no_pixel @p метка` | переход, если точка есть / нет |
| `label имя` / `goto имя` | метки и переходы |
| `run route.txt` | выполнить другой файл |
| `count` | +1 к счётчику смертей |
| `focus` | активировать окно Roblox |
| `log текст`, `release`, `stop` | сообщение в лог, отпустить все клавиши, закончить |

Клавиши: `a`–`z`, `0`–`9`, `f1`–`f12`, `space`, `shift`, `ctrl`, `alt`, `enter`, `esc`, `tab`,
`arrow_left/right/up/down` и др. Раскладка (RU/EN) не важна — используются скан-коды.
